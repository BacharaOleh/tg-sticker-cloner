# 🎭 Telegram Sticker Pack Cloner Bot

Быстрый и надежный Telegram-бот на Python (`aiogram 3`), который автоматически дублирует любой стикерпак и пересоздает его так, чтобы **владельцем набора был пользователь**.

---

## ⚡ Особенности реализации

- **Мгновенное копирование:** Стикеры не скачиваются и не загружаются заново по сети — бот передает напрямую `file_id`, благодаря чему наборы до 50 стикеров создаются **за 1 секунду**.
- **Пакетное создание (Batching):** Первые 50 стикеров передаются разом в `createNewStickerSet`. Если в наборе больше 50 стикеров, оставшиеся безопасно добавляются через `addStickerToSet`.
- **Поддержка всех типов:** Корректно определяет статичные (WEBP), анимированные (TGS) и видео-стикеры (WEBM).
- **Сохранение эмодзи:** Все привязанные эмодзи переносятся из оригинала в новый пак.
- **Защита от лимитов (Anti-Flood):** Встроен механизм повторов при `TelegramRetryAfter` и ограничение частоты редактирования сообщений прогресса.
- **Гибкий ввод:** Принимает как отдельный стикер, так и ссылку на стикерпак (`t.me/addstickers/...`) или его короткое имя.

## 🚀 Быстрый запуск

### 1. Получите токен бота
1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите имя и юзернейм для вашего бота (например, `MyStickerCloneBot`).
4. Скопируйте выданный API токен (вида `123456789:ABCdef...`).

### 2. Настройте конфигурацию
Откройте файл `.env` в папке проекта и вставьте ваш токен:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

### 3. Запуск

#### Вариант А: Через `run.bat` (в 1 клик на Windows)
Просто дважды кликните по файлу **`run.bat`**.

#### Вариант Б: Через терминал
```bash
# Активировать виртуальное окружение
.venv\Scripts\activate

# Запустить бота
python bot.py
```

---

## 📱 Как пользоваться ботом

1. Откройте вашего бота в Telegram и нажмите `/start`.
2. Отправьте ему **любой стикер** из набора, который хотите скопировать (или отправьте ссылку вида `https://t.me/addstickers/animals`).
3. Бот определит тип стикеров, создаст новый пак от вашего имени и сразу пришлет кнопку со ссылкой на добавление нового пака!
